## Project
This project is a responsive, animated practical-programs website created from the supplied assignment list.

### Sections
- HTML: 15 separate programs
- CSS: 75 separate programs
- JavaScript: 120 separate programs

**Total programs completed: 210**

## How to use
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Choose HTML, CSS, or JavaScript.
4. Select any experiment.
5. Use the working demonstration and expand **View source code** to study the implementation.

## Design features
- Responsive layout for desktop and mobile.
- Animated cards, hover effects, gradients and transitions.
- Consistent navigation on every experiment page.
- A short description is provided for every experiment.
- Every experiment is stored as a separate HTML file.
- No build process is required; the project runs by opening the files directly.

## Notes
API-based experiments use an offline-safe demonstration where a secret API key would otherwise be required. This keeps the project executable locally; an appropriate public API can be connected later if your instructor requires live data.
